# Norm Homebrew Tap

With Homebrew 7 or later, trust this project-maintained tap first:

```sh
brew trust normlanguage/tap
```

Install the Norm command-line toolchain:

```sh
brew install normlanguage/tap/normlang
norm --version
```

Update with `brew upgrade normlang` and remove with `brew uninstall normlang`.

Supported platforms follow the [Norm release targets](https://github.com/normlanguage/Norm/blob/main/cli/compiler/release-targets.json). Formula content is generated by the [Norm release pipeline](https://github.com/normlanguage/Norm/blob/main/docs/en/design/release-process.md).
